Where the numbers come from

Nothing on this site needs a paid feed or an API key. Each page paints first from a snapshot stored with the site, then asks ESPN's public scoreboard for anything newer.

What you seeSourceHow fresh
Scores, clocks and box scoresESPN public scoreboard, read by your browserEvery 20 seconds during games
Standings, leaders, injuries, rostersESPN public JSON, snapshotted when the site deploysHourly
Power index and win chancesComputed here from every final score this seasonHourly
History, GOAT Index, Rewind, Insights LabArchived box scores and schedules kept with the siteFixed, dated on each page

The power index is a schedule-adjusted rating: margins are capped so blowouts count less, recent games count more, and home court is worth about two and a half points. If ESPN is unreachable, every page still works from its last snapshot and says how old that is.
